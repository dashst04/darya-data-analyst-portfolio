# Анализ юнит-экономики контентной платформы Procrastinate Pro+

## Описание проекта

В рамках проекта проведён анализ юнит-экономики развлекательного приложения Procrastinate Pro+, предоставляющего доступ к видео, подкастам и блогам по подписке.

После запуска нового спортивного контента и изменения маркетинговой стратегии компания столкнулась со стагнацией выручки. Цель исследования — определить причины снижения эффективности привлечения пользователей, оценить окупаемость маркетинговых инвестиций и подготовить рекомендации для отдела маркетинга.

## Цель исследования

Выявить причины стагнации выручки приложения и оценить эффективность привлечения пользователей за первые 28 дней их жизненного цикла.

В рамках исследования необходимо:

* проанализировать ключевые продуктовые и финансовые метрики;
* оценить эффективность маркетинговых каналов;
* определить источники привлечения с положительной и отрицательной окупаемостью;
* подготовить рекомендации по оптимизации маркетинговой стратегии.

## Основные задачи

В ходе проекта были решены следующие задачи:

* проведена предобработка и подготовка данных;
* выполнен когортный анализ пользователей;
* рассчитаны метрики вовлечённости пользователей;
* исследованы показатели удержания пользователей (Retention Rate);
* рассчитаны метрики конверсии в покупку;
* проведён анализ стоимости привлечения пользователей (CAC);
* рассчитан жизненный цикл клиента (LTV);
* выполнен анализ окупаемости маркетинговых вложений (ROI);
* исследована эффективность каналов привлечения;
* определён период окупаемости маркетинговых инвестиций;
* подготовлены рекомендации по улучшению маркетинговой стратегии.

## Описание данных

Для анализа использовались данные о пользовательской активности, покупках и маркетинговых расходах.

### Таблица ppro_visits

Содержит информацию о посещениях приложения.

Основные поля:

* user_id — идентификатор пользователя;
* region — страна пользователя;
* device — тип устройства;
* channel — источник привлечения;
* session_start — начало сессии;
* session_end — окончание сессии.

### Таблица ppro_orders

Содержит информацию о покупках пользователей.

Основные поля:

* user_id — идентификатор пользователя;
* event_dt — дата и время покупки;
* revenue — сумма покупки.

### Таблица ppro_costs

Содержит информацию о маркетинговых расходах.

Основные поля:

* dt — дата расхода;
* channel — источник привлечения;
* costs — рекламные затраты.

## Результаты

По итогам проекта:

* проведён комплексный анализ юнит-экономики приложения;
* выявлены факторы, влияющие на снижение окупаемости маркетинговых инвестиций;
* рассчитаны показатели CAC, LTV и ROI за первые 28 дней жизненного цикла пользователей;
* определены прибыльные и убыточные каналы привлечения;
* исследовано влияние удержания и конверсии на выручку продукта;
* выявлены причины стагнации выручки после запуска нового контента;
* подготовлены рекомендации по перераспределению маркетингового бюджета и повышению эффективности привлечения пользователей.
