# Анализ A/B-тестирования онбординга в финтех-приложении SollmaFin
## Описание проекта
В рамках проекта проведён анализ исторических данных и результатов A/B-тестирования мобильного инвестиционного приложения SollmaFin.
Компания протестировала новый обучающий онбординг, который должен был повысить вовлечённость пользователей и увеличить количество повторных депозитов. 

## Цель исследования
Оценить эффективность нового онбординга и определить его влияние на поведение пользователей и бизнес-метрики приложения.

## В рамках исследования необходимо:
- проанализировать исторические данные пользователей;
- исследовать пользовательскую воронку и депозитную активность;
- проверить результаты A/B-тестирования;
- оценить влияние новой функциональности на ключевые продуктовые метрики;
- подготовить рекомендации по дальнейшему развитию продукта.

## Основные задачи
В ходе проекта были решены следующие задачи:
- проведена предобработка и подготовка данных;
- исследовано поведение новых пользователей до проведения эксперимента;
- проанализирована воронка пользовательских действий;
- рассчитаны показатели конверсии между этапами воронки;
- исследованы суммы депозитов пользователей;
- проведена оценка корректности проведения A/B-теста;
- выполнена статистическая проверка гипотез с использованием t-теста;
- проведён bootstrap-анализ распределения депозитов;
- выполнен анализ результатов по сегментам пользователей в зависимости от уровня риска активов;
- подготовлены выводы и рекомендации по внедрению новой функциональности.

## Описание данных
Для анализа использовались исторические данные пользователей и результаты A/B-эксперимента.

### Таблица pa_sollmafin_hist
Содержит исторические данные о действиях новых пользователей.
Основные поля:
`user_id` - идентификатор пользователя;
`country_code` - страна пользователя;
`platform` - тип платформы;
`first_ts` - время первого появления;
`first_dt` - дата регистрации;
`event_ts` - время события;
`event_name` - тип события;
`amount` - сумма депозита;
`asset` - приобретённый актив;
`risk_level` - уровень риска актива.

### Таблица pa_sollmafin_abt
Содержит данные пользователей, участвовавших в A/B-тестировании.
Основные поля:
`user_id` - идентификатор пользователя;
`ab_test` - название эксперимента;
`group` - группа пользователя;
`country_code` - страна;
`platform` - тип платформы;
`event_name` - действие пользователя;
`amount` - сумма депозита;
`asset` - приобретённый актив;
`risk_level` - уровень риска актива.

## Результаты
По итогам проекта:
- проведён комплексный анализ исторических данных и результатов A/B-тестирования;
- установлено, что новый онбординг не привёл к статистически значимому росту средней суммы депозитов на пользователя;
- выявлено статистически значимое увеличение конверсии из первого депозита во второй;
- определено, что наибольший положительный эффект наблюдается у пользователей, инвестирующих в активы с высоким и низким уровнем риска;
- выполнен bootstrap-анализ, позволивший выявить различия в распределении депозитов между группами;
- оценены потенциальные риски полного внедрения новой функциональности;
- подготовлены рекомендации по доработке онбординга, сегментации пользователей и проведению повторного эксперимента.
