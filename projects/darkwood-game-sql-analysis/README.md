# Анализ игровой экономики и поведения пользователей

## Описание проекта
SQL-анализ игровой экономики и поведения пользователей в игре «Секреты Темнолесья».
Исследование посвящено монетизации игры, покупательскому поведению пользователей, популярности внутриигровых предметов и различиям между пользовательскими сегментами. Дополнительно проведён поиск аномальных транзакций и проверка гипотез о влиянии характеристик персонажей на поведение игроков.

## Цель исследования
Исследовать пользовательское поведение и игровую монетизацию, выявить особенности платёжного поведения и определить факторы, которые могут быть связаны с различиями между сегментами пользователей.

Основное внимание уделено:
* доле и поведению платящих пользователей;
* структуре и стоимости внутриигровых покупок;
* популярности игровых предметов;
* различиям между сегментами игроков;
* выявлению аномальных транзакций;
* проверке продуктовых гипотез.

## Основные задачи
* расчёт доли платящих пользователей;
* анализ покупательской активности и стоимости покупок;
* сегментация пользователей по характеристикам персонажей;
* сравнение платёжного поведения различных сегментов;
* анализ популярности внутриигровых предметов;
* выявление аномальных транзакций;
* проверка гипотез о различиях пользовательского поведения;
* формирование выводов и рекомендаций для продукта.

## Данные
Для анализа использовались данные игровой базы «Секреты Темнолесья», содержащие информацию о пользователях, персонажах и внутриигровых покупках.

В исследовании использовались данные о:
* зарегистрированных пользователях;
* характеристиках игровых персонажей;
* фактах совершения платежей;
* стоимости внутриигровых покупок;
* игровых предметах;
* количестве покупок пользователей.

## Используемые инструменты
* SQL
* DBeaver

## Ключевые навыки
* SQL-аналитика;
* агрегация и группировка данных;
* расчёт продуктовых и финансовых метрик;
* сегментация пользователей;
* анализ покупательского поведения;
* анализ монетизации;
* сравнение пользовательских сегментов;
* выявление аномалий;
* проверка продуктовых гипотез;
* интерпретация результатов и формирование рекомендаций.

## Этапы анализа
1. Исследование структуры базы данных.
2. Анализ платящих пользователей.
3. Расчёт метрик игровой монетизации.
4. Анализ стоимости и структуры покупок.
5. Выявление аномальных транзакций.
6. Анализ популярности игровых предметов.
7. Сегментация и сравнение пользователей.
8. Проверка продуктовых гипотез.
9. Формирование выводов и рекомендаций.

## Результаты

В результате анализа:
* доля платящих пользователей составила около 18%;
* существенной зависимости между выбранной расой и вероятностью совершения платежа не выявлено;
* выявлены аномальные транзакции с нулевой стоимостью, требующие дополнительной проверки;
* определены наиболее популярные внутриигровые предметы;
* выявлена высокая концентрация покупок на двух наиболее популярных предметах;
* обнаружены различия в покупательской активности между пользовательскими сегментами;
* сформированы рекомендации по дальнейшему анализу монетизации и баланса игрового процесса.
