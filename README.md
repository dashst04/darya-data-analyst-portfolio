# Портфолио проектов по анализу данных

Привет! Меня зовут Дарья.

В этом репозитории собраны мои проекты по анализу данных, выполненные в процессе обучения и практики.

Моя цель - развивать навыки анализа данных, продуктовой аналитики и принятия решений на основе данных.

Инструменты и технологии:
- Python (pandas, numpy, seaborn, matplotlib, scipy)
- SQL
- Excel / Google Sheets
- Jupyter Notebook
- DBeaver
- Yandex DataLens

Проекты включают:
- разведочный анализ данных
- визуализацию данных
- работу с реальными датасетами
- получение бизнес-инсайтов на основе данных

## Проекты
Проекты расположены в хронологическом порядке их выполнения - от первых учебных кейсов до более комплексных аналитических исследований с использованием продуктовых метрик, SQL, Python и A/B-тестирования.

### Анализ данных для салона красоты Waves
Анализ финансовых показателей, промокампаний и спроса на товары и услуги салона красоты в Google Sheets.

### Анализ рынка вакансий аналитиков
Анализ требований работодателей и уровня зарплат.

### Анализ активности доноров DonorSearch
Исследование факторов, влияющих на активность доноров.

### Анализ рынка недвижимости
Исследование сегментов недвижимости Санкт-Петербурга и Ленинградской области.

### Анализ финансирования стартапов
Исследование структуры инвестиций и эффективности различных типов финансирования.

### Анализ игровой экономики «Секреты Темнолесья»
Исследование монетизации, внутриигровых покупок и активности игроков с использованием SQL. Анализ доли платящих пользователей, популярности игровых предметов и влияния расы персонажа на игровое поведение.

### Анализ конференций TED и разработка дашборда
Разработка интерактивного дашборда для анализа TED-конференций в SQL и DataLens. Исследование популярных тем, характеристик выступлений, активности аудитории и востребованности спикеров.

### Анализ рынка видеоигр
Исследование данных о продажах видеоигр с использованием Python и Pandas. Проведена предобработка данных, анализ игровых платформ, категоризация оценок пользователей и критиков, а также подготовка аналитического датасета для изучения тенденций игровой индустрии.

### Анализ рынка общественного питания Москвы
Исследование рынка кафе, ресторанов и кофеен Москвы с использованием Python и Pandas. Проведён анализ структуры рынка, сетевых заведений, рейтингов, среднего чека и территориального распределения объектов для подготовки рекомендаций по открытию нового заведения.

### Анализ бизнес-метрик сервиса доставки еды
Разработка интерактивного дашборда в Yandex DataLens для мониторинга ключевых метрик сервиса доставки еды. Выполнен расчёт DAU, Conversion Rate, среднего чека, LTV и Retention Rate с использованием SQL, а также подготовлены аналитические рекомендации по развитию продукта.

### Разработка и анализ A/B-теста рекомендательной системы
Проведение полного цикла A/B-тестирования для оценки нового алгоритма рекомендаций в мобильном приложении. Выполнен расчёт параметров эксперимента, анализ тестовой и контрольной групп, статистическая проверка гипотез и оценка влияния изменений на пользовательскую активность.

### Анализ пользовательской активности в Яндекс Книгах и A/B-тестирование
Расчёт продуктовых метрик в SQL (LTV, Retention, популярность контента), проверка статистических гипотез в Python и анализ результатов A/B-теста пользовательского интерфейса.

### Анализ юнит-экономики контентной платформы Procrastinate Pro+
Когортный анализ пользователей, расчёт метрик CAC, LTV, ROI, Retention и Conversion Rate в Python. Исследование эффективности маркетинговых каналов и выявление причин стагнации выручки продукта.

### Анализ результатов A/B-тестирования финтех-приложения SollmaFin
Проведён анализ исторических данных и результатов A/B-теста в Python. Выполнена оценка продуктовых метрик, статистическая проверка гипотез и bootstrap-анализ распределения депозитов для подготовки рекомендаций по внедрению новой функции онбординга.

### Анализ продуктовых метрик маркетплейса
Комплексный анализ продуктовых и финансовых метрик маркетплейса с расчётом MAU, DAU, ARPU, ARPPU, AOV, Retention, CAC, ROI и Payback Period. Выполнена сегментация пользователей, поиск точек роста и подготовка гипотез для развития продукта и последующих A/B-тестов.

В репозиторий также будут добавляться еще и новые проекты.
