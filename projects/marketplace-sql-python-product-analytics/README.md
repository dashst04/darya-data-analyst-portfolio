# Анализ продуктовых метрик маркетплейса с помощью SQL и Python

## Описание проекта
Комплексный анализ пользовательского поведения, продуктовых метрик, монетизации и юнит-экономики быстрорастущего маркетплейса.
В рамках проекта данные из нескольких источников были объединены и подготовлены для анализа с помощью SQL и Python. Исследование охватывает пользовательскую воронку, активность и удержание клиентов, монетизацию, эффективность маркетинговых каналов и юнит-экономику продукта.

## Цель проекта
Оценить текущее состояние продукта, определить основные драйверы роста и выявить возможности для повышения конверсии, удержания пользователей и эффективности маркетинговых инвестиций.

## Основные задачи
* провести предобработку и объединение данных из нескольких источников;
* обработать JSON-поля и подготовить аналитические витрины;
* рассчитать ключевые продуктовые метрики;
* проанализировать пользовательскую воронку;
* исследовать монетизацию и юнит-экономику;
* оценить эффективность каналов привлечения;
* провести сегментацию пользователей;
* выявить точки роста продукта;
* сформулировать продуктовые гипотезы и рекомендации.

## Продуктовые и бизнес-метрики
В рамках проекта рассчитаны и проанализированы:
* **DAU / WAU / MAU** - пользовательская активность;
* **CTR** - взаимодействие пользователей с контентом;
* **Conversion Rate** - конверсия между этапами воронки;
* **Retention Rate** - удержание пользователей;
* **AOV** - средняя стоимость заказа;
* **ARPU / ARPPU** - выручка на пользователя и платящего пользователя;
* **CAC** - стоимость привлечения клиента;
* **LTV** - пожизненная ценность клиента;
* **ROI** - окупаемость маркетинговых инвестиций;
* **Payback Period** - период окупаемости.

## Данные
Для анализа использовались данные о пользователях, заказах, товарах, пользовательских событиях и маркетинговых расходах.

### Users
Информация о зарегистрированных пользователях:
  * `user_id` - идентификатор пользователя;
  * `registration_date` - дата регистрации;
  * `user_params` - JSON с характеристиками пользователя.

### Orders
Информация о заказах:
  * `order_id` - идентификатор заказа;
  * `user_id` - идентификатор пользователя;
  * `order_date` - дата заказа;
  * `product_id` - идентификатор товара;
  * `quantity` - количество товара;
  * `unit_price` - стоимость единицы товара;
  * `total_price` - стоимость позиции заказа.

### Product_dict
Справочник товаров:
  * `product_id` - идентификатор товара;
  * `category_id` - идентификатор категории;
  * `category_name` - категория товара;
  * `product_name` - название товара.

### Events
Данные о пользовательских действиях:
  * `event_id` - идентификатор события;
  * `user_id` - идентификатор пользователя;
  * `timestamp` - дата и время события;
  * `event_type` - тип события;
  * `product_id` - идентификатор товара;
  * `event_params` - JSON с дополнительными параметрами события.

### Campaigns
Данные о маркетинговых расходах:
  * `acq_channel` - канал привлечения;
  * `spend_month` - месяц рекламной кампании;
  * `budget` - рекламный бюджет.
