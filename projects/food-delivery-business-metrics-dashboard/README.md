# Анализ ключевых бизнес-метрик сервиса доставки еды

## Dashboard
🔗 Ссылка на дашборд: (https://datalens.yandex/tr8gmn9aayzid)

## Описание проекта

В рамках проекта разработан аналитический дашборд для сервиса доставки еды «Всё.из.кафе». Цель исследования — оценить состояние клиентской базы в городе Саранске и проанализировать динамику ключевых продуктовых и бизнес-метрик.

Проект включает подготовку данных с помощью SQL-запросов, создание интерактивного дашборда в DataLens и формирование аналитического отчёта с выводами и рекомендациями для бизнеса.

## Цель исследования

Оценить эффективность работы сервиса доставки еды на основе ключевых продуктовых метрик и выявить тенденции в поведении пользователей.

В рамках исследования необходимо определить:

* как меняется активность пользователей во времени;
* насколько эффективно сервис конвертирует посетителей в покупателей;
* как изменяется средний чек заказов;
* какую ценность приносят пользователи за время взаимодействия с сервисом;
* насколько успешно сервис удерживает клиентов.

## Основные задачи

В ходе проекта были решены следующие задачи:

* подготовлены SQL-запросы для расчёта ключевых бизнес-метрик;
* рассчитан показатель DAU (Daily Active Users);
* проведён анализ Conversion Rate;
* рассчитан средний чек пользователей;
* выполнен расчёт LTV (Lifetime Value);
* исследован показатель Retention Rate;
* разработаны визуализации для каждой метрики;
* создан интерактивный дашборд в Yandex DataLens;
* подготовлен аналитический отчёт по результатам исследования.

## Описание данных

Для анализа использованы данные сервиса доставки еды, включающие пользовательскую активность, заказы, рекламные расходы и справочную информацию о ресторанах.

### Таблица analytics_events

Содержит журнал пользовательских действий в сервисе.

Основные поля:

* visitor_uuid — идентификатор посетителя;
* user_id — идентификатор зарегистрированного пользователя;
* source — источник привлечения;
* event — тип события;
* datetime — дата и время события;
* order_id — идентификатор заказа;
* revenue — сумма заказа;
* commission — комиссия сервиса.

### Таблица advertisement_budgets

Содержит информацию о рекламных расходах.

Основные поля:

* source — рекламный канал;
* date — дата;
* budget — рекламный бюджет.

### Таблица partners

Справочник партнёрских ресторанов.

### Таблица dishes

Справочник блюд.

### Таблица cities

Справочник городов сервиса.

## Этапы работы

1. Изучение структуры базы данных.
2. Подготовка SQL-запросов для расчёта метрик.
3. Расчёт DAU, Conversion Rate, Average Check, LTV и Retention Rate.
4. Проверка корректности вычислений.
5. Разработка визуализаций в DataLens.
6. Создание интерактивного дашборда.
7. Анализ динамики показателей.
8. Подготовка аналитического отчёта и рекомендаций.

## Структура дашборда

Дашборд включает следующие показатели:

### Активность пользователей

* DAU (ежедневная аудитория);
* динамика пользовательской активности.

### Конверсия

* Conversion Rate;
* изменение конверсии по дням.

### Финансовые показатели

* средний чек;
* LTV пользователей;
* динамика выручки.

### Удержание пользователей

* Retention Rate;
* анализ возврата пользователей по когортам.
