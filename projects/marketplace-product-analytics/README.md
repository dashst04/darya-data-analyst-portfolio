# Анализ продуктовых метрик и юнит-экономики маркетплейса

## Описание проекта
В рамках проекта проведён комплексный анализ продуктовых метрик и юнит-экономики быстрорастущего маркетплейса.

## Цель исследования
Оценить эффективность работы маркетплейса, определить основные драйверы роста продукта и выявить возможности для повышения прибыльности.

## В рамках исследования необходимо:
* проанализировать ключевые продуктовые метрики;
* оценить показатели монетизации и юнит-экономики;
* исследовать поведение пользователей на различных этапах воронки;
* выявить наиболее эффективные пользовательские сегменты и каналы привлечения;
* сформулировать гипотезы для дальнейшего развития продукта.

## Основные задачи
В ходе проекта были решены следующие задачи:
* выполнена предобработка и объединение данных из нескольких источников;
* обработаны JSON-поля и подготовлены аналитические витрины;
* проведён анализ пользовательской активности;
* рассчитаны ключевые продуктовые метрики (DAU, WAU, MAU, ARPU, ARPPU, AOV, Retention Rate, CTR, Conversion Rate);
* выполнен анализ монетизации и юнит-экономики;
* рассчитаны показатели CAC, ROI и Payback Period;
* исследована эффективность каналов привлечения пользователей;
* проведена сегментация пользователей по регионам, устройствам, категориям товаров и каналам привлечения;
* выявлены точки роста продукта и сформулированы продуктовые гипотезы;
* подготовлены аналитические рекомендации для развития маркетплейса.

## Описание данных
Для анализа использовались данные о пользователях, заказах, событиях, товарах и маркетинговых расходах.

### Таблица Users
Содержит информацию о зарегистрированных пользователях.
Основные поля:
* `user_id` — идентификатор пользователя;
* `registration_date` — дата регистрации;
* `user_params` — JSON с характеристиками пользователя (возраст, пол, регион, сегмент, канал привлечения).

### Таблица Orders
Содержит информацию о заказах пользователей.
Основные поля:
* `order_id` — идентификатор заказа;
* `user_id` — идентификатор пользователя;
* `order_date` — дата оформления заказа;
* `product_id` — идентификатор товара;
* `quantity` — количество товара;
* `unit_price` — стоимость единицы товара;
* `total_price` — стоимость позиции заказа.

### Таблица Product_dict
Содержит справочник товаров.
Основные поля:
* `product_id` — идентификатор товара;
* `category_id` — идентификатор категории;
* `category_name` — категория товара;
* `product_name` — наименование товара.

### Таблица Events
Содержит данные о действиях пользователей.
Основные поля:
* `event_id` — идентификатор события;
* `user_id` — идентификатор пользователя;
* `timestamp` — дата и время события;
* `event_type` — тип события;
* `product_id` — идентификатор товара;
* `event_params` — JSON с дополнительными параметрами события.

### Таблица Campaigns
Содержит информацию о маркетинговых расходах.
Основные поля:
* `acq_channel` — канал привлечения;
* `spend_month` — месяц рекламной кампании;
* `budget` — рекламный бюджет.
