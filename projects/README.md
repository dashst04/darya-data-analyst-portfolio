# Проекты

Подборка проектов по анализу данных, продуктовой аналитике и автоматизации обработки данных.

Проекты охватывают работу с **SQL и базами данных, Python, продуктовой аналитикой, A/B-тестированием, юнит-экономикой, пользовательским поведением, BI-дашбордами и ETL-процессами**.
