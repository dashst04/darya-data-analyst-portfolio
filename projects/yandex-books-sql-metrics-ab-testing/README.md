# Анализ пользовательской активности и проверка гипотез в сервисе Яндекс Книги

## Описание проекта

В рамках проекта проведён анализ пользовательской активности сервиса Яндекс Книги с использованием SQL и Python. Исследование включало расчёт продуктовых метрик, анализ поведения пользователей, проверку бизнес-гипотезы и оценку результатов A/B-тестирования.

Проект демонстрирует навыки работы с продуктовыми метриками, статистическим анализом, проверкой гипотез и оценкой эффективности продуктовых изменений на основе данных.

## Цель исследования

Изучить поведение пользователей сервиса Яндекс Книги, рассчитать ключевые продуктовые метрики и проверить гипотезу о различиях в активности пользователей из Москвы и Санкт-Петербурга.

Дополнительно провести анализ результатов A/B-теста интернет-магазина и оценить влияние изменений интерфейса на конверсию пользователей.

## Основные задачи

В рамках проекта были решены следующие задачи:

* рассчитаны продуктовые метрики с использованием SQL;
* определены наиболее популярные авторы и произведения;
* проведён анализ удержания пользователей и LTV;
* исследована динамика средней выручки на час активности;
* выполнено сравнение пользовательской активности в Москве и Санкт-Петербурге;
* подготовлены данные для статистической проверки гипотез;
* проведена проверка статистической значимости различий между группами пользователей;
* проанализирована корректность проведения A/B-теста;
* выполнена оценка влияния нового интерфейса на конверсию пользователей;
* подготовлены аналитические выводы и рекомендации.

## Описание данных

Для анализа использовались данные сервиса Яндекс Книги за период с сентября по декабрь 2024 года.

### Таблица audition

Содержит информацию о пользовательской активности.

Основные поля:

* audition_id — идентификатор сессии;
* puid — идентификатор пользователя;
* usage_platform_ru — платформа использования сервиса;
* hours — длительность чтения или прослушивания;
* hours_sessions_long — длительность длинных сессий;
* main_content_id — идентификатор контента;
* usage_geo_id — идентификатор региона пользователя.

### Таблица content

Содержит информацию о книгах и аудиокнигах.

Основные поля:

* main_content_id — идентификатор контента;
* main_author_id — идентификатор автора;
* main_content_name — название произведения;
* main_content_type — тип контента;
* published_topic_title_list — жанры произведения.

### Таблица author

Содержит информацию об авторах.

Основные поля:

* main_author_id — идентификатор автора;
* main_author_name — имя автора.

### Таблица geo

Содержит информацию о географическом расположении пользователей.

Основные поля:

* usage_geo_id — идентификатор региона;
* usage_geo_id_name — название региона или города;
* usage_country_name — страна пользователя.

### Данные A/B-теста

Для анализа результатов эксперимента использовались данные о пользователях интернет-магазина, их действиях и принадлежности к тестовым группам.
