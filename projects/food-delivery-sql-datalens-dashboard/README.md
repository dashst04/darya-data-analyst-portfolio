## Описание проекта
Проект по анализу пользовательской активности и ключевых бизнес-метрик сервиса доставки еды «Всё.из.кафе».
В рамках проекта с помощью SQL подготовлены данные для расчёта продуктовых метрик, после чего результаты визуализированы в интерактивном дашборде Yandex DataLens.
Основное внимание уделено пользовательской активности, конверсии, среднему чеку, LTV и удержанию клиентов.

## Цель проекта
Оценить динамику ключевых продуктовых и бизнес-метрик сервиса и выявить изменения в поведении пользователей.

В рамках анализа:
* исследована динамика пользовательской активности;
* рассчитана конверсия посетителей в покупателей;
* проанализирован средний чек;
* рассчитан LTV пользователей;
* проведён когортный анализ Retention Rate;
* подготовлены визуализации и аналитические выводы.

## Данные
Для анализа использовались данные о пользовательских событиях, заказах, рекламных расходах и партнёрах сервиса.
Основная таблица `analytics_events` содержит информацию о действиях пользователей и заказах:
  * `visitor_uuid` - идентификатор посетителя;
  * `user_id` - идентификатор пользователя;
  * `source` - источник привлечения;
  * `event` - тип события;
  * `datetime` - дата и время события;
  * `order_id` - идентификатор заказа;
  * `revenue` - сумма заказа;
  * `commission` - комиссия сервиса.

Дополнительно использовались таблицы с рекламными расходами и справочной информацией о ресторанах, блюдах и городах.

## Основные метрики
В проекте рассчитаны:
* **DAU** - ежедневная активная аудитория;
* **Conversion Rate** - конверсия пользователей в покупателей;
* **Average Check** - средний чек;
* **LTV** - пожизненная ценность пользователя;
* **Retention Rate** - удержание пользователей.
