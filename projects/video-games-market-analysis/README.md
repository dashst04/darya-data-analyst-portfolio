# Анализ рынка видеоигр

## Описание проекта

В рамках проекта проведён анализ рынка видеоигр начала XXI века на основе данных о продажах игр, игровых платформах, жанрах и пользовательских оценках. Особое внимание уделено исследованию рынка RPG-игр, а также изучению региональных особенностей продаж и популярности игровых платформ.

Проект включает полный цикл подготовки данных: исследование структуры датасета, обработку пропусков и дубликатов, преобразование типов данных, категоризацию игр по оценкам пользователей и критиков, а также формирование аналитического среза для дальнейших исследований игровой индустрии.

## Цель исследования

Подготовить качественный аналитический датасет и изучить развитие рынка видеоигр в период с 2000 по 2013 год.

В рамках исследования необходимо определить:

* какие игровые платформы были наиболее популярны;
* как распределяются продажи игр по регионам;
* как оценки пользователей и критиков характеризуют игровые продукты;
* какие платформы выпустили наибольшее количество игр;
* какие данные могут быть использованы для дальнейшего анализа рынка RPG-игр.

## Основные задачи

В ходе проекта были решены следующие задачи:

* проведено исследование структуры и качества исходных данных;
* выполнена проверка корректности типов данных;
* обработаны пропущенные значения;
* выявлены и устранены явные и неявные дубликаты;
* стандартизированы названия столбцов и категориальных признаков;
* выполнена фильтрация данных по периоду 2000–2013 годов;
* проведена категоризация игр по оценкам пользователей;
* проведена категоризация игр по оценкам критиков;
* определены топ-7 игровых платформ по количеству выпущенных игр;
* подготовлен аналитический датасет для последующего исследования рынка видеоигр.

## Описание данных

Для анализа использован датасет с информацией о продажах видеоигр, игровых платформах и пользовательских оценках.

Основные поля:

* name — название игры;
* platform — игровая платформа;
* year_of_release — год выпуска;
* genre — жанр игры;
* na_sales — продажи в Северной Америке;
* eu_sales — продажи в Европе;
* jp_sales — продажи в Японии;
* other_sales — продажи в других регионах;
* critic_score — оценка критиков;
* user_score — оценка пользователей;
* rating — возрастной рейтинг ESRB.

## Этапы анализа

1. Загрузка и первичное исследование данных.
2. Проверка качества данных.
3. Обработка пропусков и дубликатов.
4. Приведение данных к единому формату.
5. Преобразование типов данных.
6. Фильтрация данных по периоду исследования.
7. Категоризация оценок пользователей и критиков.
8. Выделение наиболее популярных игровых платформ.
9. Формирование итогового аналитического датасета.

## Результаты

По итогам проекта:

* выполнена категоризация игр по пользовательским и экспертным оценкам;
* выделены наиболее активные игровые платформы периода 2000–2013 годов;
* устранены ошибки качества данных, влияющие на результаты анализа;
