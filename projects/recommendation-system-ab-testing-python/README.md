# A/B-тест рекомендательной системы - Python и статистический анализ

## О проекте
Анализ A/B-теста нового алгоритма рекомендаций в мобильном приложении с бесконечной лентой контента.
Задача эксперимента - определить, приводит ли новый алгоритм к изменению пользовательского поведения и росту вовлечённости, а также проверить, можно ли доверять полученным результатам с точки зрения качества эксперимента и статистической значимости.
Проект охватывает полный цикл анализа A/B-теста: от определения параметров эксперимента и проверки рандомизации до статистической оценки результатов и формирования рекомендации по внедрению изменения.

## Цель
Оценить влияние нового алгоритма рекомендаций на ключевые показатели пользовательского поведения и принять решение о его внедрении.

## Данные
Для анализа использованы данные пользовательских сессий мобильного приложения.

### Исторические данные
Данные о пользовательской активности до проведения эксперимента:
  * `user_id` - идентификатор пользователя;
  * `session_id` - идентификатор сессии;
  * `session_date` - дата сессии;
  * `install_date` - дата установки приложения;
  * `session_number` - номер сессии пользователя;
  * `page_counter` - количество просмотренных страниц;
  * `registration_flag` - признак регистрации;
  * `region` - регион пользователя;
  * `device` - тип устройства.

### Данные эксперимента
Данные о пользователях контрольной и тестовой групп в период проведения A/B-теста.
  * дополнительное поле `test_group` - принадлежность пользователя к контрольной или тестовой группе.

## Методология
Анализ проведён в несколько этапов.
### 1. Подготовка данных
  * исследование структуры и качества данных;
  * проверка типов и пропущенных значений;
  * анализ пользовательской активности;
  * подготовка данных для расчёта продуктовых метрик.

### 2. Проектирование эксперимента
  * определение ключевых метрик;
  * расчёт параметров A/B-теста;
  * определение необходимого размера выборки;
  * оценка требований к эксперименту.

### 3. Проверка качества эксперимента
  * проверка распределения пользователей по группам;
  * оценка баланса контрольной и тестовой групп;
  * сравнение основных характеристик пользователей;
  * проверка корректности рандомизации.

### 4. Анализ результатов
  * сравнение ключевых метрик контрольной и тестовой групп;
  * оценка изменения пользовательского поведения;
  * формулирование статистических гипотез;
  * проверка статистической значимости различий;
  * интерпретация результатов с точки зрения продуктового эффекта.

### 5. Продуктовое решение
На основании статистических результатов и величины выявленного эффекта сформирована рекомендация по дальнейшему использованию нового алгоритма рекомендаций.

## Используемые инструменты
  * **Python** - основной язык анализа;
  * **Pandas** - подготовка и анализ данных;
  * **SciPy** - статистические тесты;
  * **Statsmodels** - статистический анализ и расчёты для эксперимента;
  * **Matplotlib / Seaborn** - визуализация;
  * **Jupyter Notebook** - среда проведения анализа.

## Ключевые навыки
**A/B-тестирование**
  * дизайн эксперимента;
  * определение параметров теста;
  * расчёт размера выборки;
  * контрольная и тестовая группы;
  * проверка рандомизации.

**Статистический анализ**
  * формулирование статистических гипотез;
  * оценка статистической значимости;
  * сравнение групп;
  * интерпретация результатов статистических тестов.

**Продуктовая аналитика**
  * анализ пользовательского поведения;
  * формирование продуктовых метрик;
  * оценка вовлечённости;
  * оценка эффекта продуктового изменения;
  * принятие решения на основе данных.

## Результаты
В результате анализа:
* определены параметры проведения A/B-теста;
* рассчитан необходимый размер выборки;
* проверена корректность распределения пользователей между группами;
* проведена оценка сопоставимости контрольной и тестовой групп;
* проанализировано изменение пользовательского поведения;
* выполнена статистическая проверка различий между группами;
* оценена статистическая значимость результатов;
* сформирована рекомендация по внедрению или дальнейшей доработке алгоритма.
