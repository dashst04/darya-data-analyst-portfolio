# Автоматизация обработки данных о поездках Яндекс Такси

## Описание проекта
В рамках проекта разработан автоматизированный процесс обработки данных о поездках Яндекс Такси. Необходимо было построить витрину данных с ключевыми показателями по каждому способу оплаты и настроить её регулярное обновление.
Для обработки данных использован PySpark, а автоматизация загрузки и формирования витрины реализована с помощью Apache Airflow. Итоговые данные записываются в ClickHouse и могут использоваться финансовыми и продуктовыми командами для дальнейшего анализа и построения отчётности.

## Цель проекта
Разработать автоматизированный ETL-процесс, который ежедневно обрабатывает новые данные о поездках и формирует аналитическую витрину с ключевыми показателями по способам оплаты.

## Основные задачи
* Загрузить данные о поездках из Parquet-файла в S3.
* Обработать и агрегировать данные с помощью PySpark.
* Рассчитать ключевые показатели по каждому способу оплаты.
* Сформировать итоговую таблицу `taxi_payment_summary`.
* Настроить запись витрины в ClickHouse через JDBC.
* Создать DAG в Apache Airflow для автоматизации процесса.
* Настроить проверку появления новых файлов в S3.
* Организовать последовательный запуск Spark-задачи после появления данных.

## Описание данных
Таблица `taxi_data` содержит информацию о поездках:
* `taxi_id` — идентификатор водителя;
* `trip_start_timestamp` — время начала поездки;
* `trip_end_timestamp` — время окончания поездки;
* `trip_seconds` — длительность поездки;
* `trip_miles` — дистанция поездки;
* `fare` — стоимость поездки;
* `tips` — чаевые;
* `trip_total` — общая стоимость поездки;
* `payment_type` — способ оплаты.

## Используемые инструменты
* PySpark
* *Apache Airflow
* ClickHouse
* S3
* Dataproc
* JDBC
* Python.

## Этапы работы
1. Загрузка данных из S3 в формате Parquet.
2. Обработка данных с использованием PySpark.
3. Группировка поездок по способу оплаты.
4. Расчёт количества поездок, средней стоимости поездки, средних чаевых и суммарной выручки.
5. Формирование витрины `taxi_payment_summary`.
6. Запись результатов в ClickHouse через JDBC.
7. Создание DAG в Airflow.
8. Настройка `S3KeySensor` для проверки появления новых данных.
9. Запуск Spark-задачи через `DataprocCreatePysparkJobOperator`.
10. Автоматизация ежедневного обновления витрины.

## Результаты
* Разработана аналитическая витрина с показателями поездок по способам оплаты.
* Автоматизирована обработка данных с использованием PySpark.
* Настроена ежедневная оркестрация ETL-процесса в Apache Airflow.
* Реализована проверка появления новых данных в S3 перед запуском обработки.
* Настроена загрузка результатов в ClickHouse.
* Сформирован воспроизводимый процесс подготовки данных для дальнейшей отчётности и аналитики.
