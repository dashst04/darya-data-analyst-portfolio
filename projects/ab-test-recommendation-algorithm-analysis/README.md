# Разработка и анализ A/B-теста рекомендательной системы

## Описание проекта

В рамках проекта проведена подготовка и анализ A/B-теста для проверки эффективности нового алгоритма рекомендаций в развлекательном мобильном приложении с бесконечной лентой контента.

Основная задача исследования — определить, способен ли новый алгоритм повысить вовлечённость пользователей за счёт более релевантного контента, а также оценить корректность проведения эксперимента и статистическую значимость полученных результатов.

## Цель исследования

Оценить влияние нового алгоритма рекомендаций на пользовательское поведение и определить целесообразность его внедрения в продукт.

В рамках исследования необходимо:

* рассчитать параметры A/B-теста;
* проверить корректность распределения пользователей между группами;
* оценить качество проведения эксперимента;
* проанализировать влияние изменений на ключевые продуктовые метрики;
* принять решение о внедрении нового алгоритма.

## Основные задачи

В ходе проекта были решены следующие задачи:

* проведён анализ исторических данных пользователей;
* определены ключевые продуктовые метрики для тестирования;
* рассчитаны параметры эксперимента и необходимый размер выборки;
* выполнена проверка корректности рандомизации;
* исследован баланс тестовой и контрольной групп;
* проведён анализ поведения пользователей в период эксперимента;
* выполнена статистическая проверка гипотез;
* оценена значимость полученных результатов;
* подготовлены рекомендации по итогам эксперимента.

## Описание данных

Для анализа использованы данные пользовательских сессий мобильного приложения.

### Исторические данные

Содержат информацию о пользовательской активности до запуска эксперимента.

Основные поля:

* user_id — идентификатор пользователя;
* session_id — идентификатор сессии;
* session_date — дата сессии;
* install_date — дата установки приложения;
* session_number — номер сессии пользователя;
* page_counter — количество просмотренных страниц;
* registration_flag — признак регистрации пользователя;
* region — регион пользователя;
* device — тип устройства.

### Данные A/B-теста

Содержат данные пользователей контрольной и тестовой групп в период проведения эксперимента.

Дополнительное поле:

* test_group — принадлежность пользователя к контрольной или тестовой группе.
