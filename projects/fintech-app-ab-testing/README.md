# A/B-тестирование онбординга в финтех-приложении

## Описание проекта
Анализ пользовательского поведения и результатов A/B-тестирования нового онбординга в мобильном инвестиционном приложении.
Исследование включает анализ пользовательской воронки, депозитной активности и результатов эксперимента. Отдельное внимание уделено проверке корректности A/B-теста, статистической значимости изменений и различиям эффекта между пользовательскими сегментами.

## Цель исследования
Оценить влияние нового онбординга на пользовательское поведение и ключевые продуктовые метрики приложения, а также определить целесообразность его внедрения.

## Основные задачи
* подготовка и исследование исторических данных;
* анализ пользовательской воронки;
* расчёт конверсий между этапами воронки;
* анализ депозитной активности пользователей;
* проверка корректности проведения A/B-теста;
* статистическое сравнение контрольной и тестовой групп;
* анализ различий в результатах эксперимента по сегментам пользователей;
* оценка практического эффекта изменения;
* формирование рекомендаций по результатам эксперимента.

## Данные
Для анализа использовались исторические данные о действиях пользователей и данные A/B-теста.

### `pa_sollmafin_hist`
Исторические данные о действиях новых пользователей:
  * `user_id` - идентификатор пользователя;
  * `country_code` - страна пользователя;
  * `platform` - платформа;
  * `first_ts` - время первого появления;
  * `first_dt` - дата регистрации;
  * `event_ts` - время события;
  * `event_name` - тип события;
  * `amount` - сумма депозита;
  * `asset` - приобретённый актив;
  * `risk_level` - уровень риска актива.

### `pa_sollmafin_abt`
Данные пользователей, участвовавших в A/B-тестировании:
  * `user_id` - идентификатор пользователя;
  * `ab_test` - название эксперимента;
  * `group` - экспериментальная группа;
  * `country_code` - страна пользователя;
  * `platform` - платформа;
  * `event_name` - действие пользователя;
  * `amount` - сумма депозита;
  * `asset` - приобретённый актив;
  * `risk_level` - уровень риска актива.
