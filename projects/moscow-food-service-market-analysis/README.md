# Анализ рынка общественного питания Москвы

## Описание проекта

В рамках проекта проведён исследовательский анализ рынка общественного питания Москвы на основе данных сервисов Яндекс Карты и Яндекс Бизнес. Исследование направлено на изучение структуры рынка, особенностей размещения заведений, ценовой политики, рейтингов и конкурентной среды.

Результаты анализа позволяют оценить текущее состояние рынка общественного питания и сформировать рекомендации для инвесторов по выбору формата будущего заведения и его расположения.

## Цель исследования

Провести исследовательский анализ рынка общественного питания Москвы и определить наиболее перспективные направления для открытия нового заведения.

В рамках исследования необходимо ответить на следующие вопросы:

* какие категории заведений наиболее распространены;
* как распределены заведения по административным округам Москвы;
* насколько распространены сетевые заведения;
* какие характеристики отличают разные категории общепита;
* как формируются рейтинги заведений;
* как различаются цены в зависимости от района города;
* какие сети являются наиболее популярными на рынке.

## Основные задачи

В ходе анализа были решены следующие задачи:

* выполнено объединение и подготовка данных из нескольких источников;
* проведена обработка пропусков и дубликатов;
* создан признак круглосуточной работы заведения;
* исследована структура рынка общественного питания по категориям;
* проанализировано распределение заведений по административным округам Москвы;
* изучено соотношение сетевых и несетевых заведений;
* проведён анализ количества посадочных мест;
* исследованы рейтинги заведений различных категорий;
* выполнен корреляционный анализ факторов, влияющих на рейтинг;
* определены наиболее популярные сети общественного питания;
* проанализированы различия среднего чека по районам Москвы;
* сформированы рекомендации для потенциальных инвесторов.

## Описание данных

Для анализа использованы данные о заведениях общественного питания Москвы за 2022 год.

### Таблица rest_info

Содержит информацию о заведениях.

Основные поля:

* name — название заведения;
* address — адрес;
* district — административный округ;
* category — категория заведения;
* hours — режим работы;
* rating — пользовательский рейтинг;
* chain — принадлежность к сети;
* seats — количество посадочных мест.

### Таблица rest_price

Содержит информацию о ценах.

Основные поля:

* price — ценовая категория;
* avg_bill — информация о среднем чеке;
* middle_avg_bill — оценка среднего чека;
* middle_coffee_cup — стоимость чашки капучино.
